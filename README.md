# 🔐 DecodeLabs Cybersecurity Project 2
## Basic Encryption & Decryption

A Python-based implementation of the Caesar Cipher demonstrating basic encryption and decryption concepts.

This project was developed as part of the DecodeLabs Cybersecurity Internship — Project 2.

## 📌 Project Overview

The program encrypts user-provided text using a Caesar Cipher and then decrypts the encrypted text back to its original form.

The user can provide a custom shift key between 1 and 25.

## 🎯 Requirements Covered

- Encrypt user text using a basic encryption technique
- Decrypt the encrypted text
- Display the encrypted output
- Display the decrypted output
- Allow the user to choose a shift key

## 🚀 Features

### Caesar Cipher Encryption

Each alphabetic character is shifted by the user-selected number of positions.

### Decryption

The encrypted text can be reversed using the same shift key.

### Custom Shift Key

Users can select a shift value between 1 and 25.

### Character Preservation

Spaces, numbers and special characters remain unchanged.

### Input Validation

The program validates the shift key and handles invalid input.

## 🛠️ Technologies Used

- Python 3
- String Handling
- Conditional Logic
- ASCII/Unicode Character Operations
- Modular Arithmetic
